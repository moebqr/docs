## Prerequisites

Before you begin, make sure you have:

- A Servable account ([Sign up here](https://servable.dev))
- Node.js 18+ installed
- Basic knowledge of AI/ML concepts

## Installation

Install the Servable CLI to get started:

```bash
npm install -g @servable/cli
```

## Authentication

Authenticate with your Servable account:

```bash
servable auth login
```

This will open your browser to complete the authentication process.

## Your First Project

Create a new project:

```bash
servable init my-ai-project
cd my-ai-project
```

## Generate Your First Dataset

Use the Data Agent to create a training dataset:

```bash
servable data-agent create \
  --task "sentiment-analysis" \
  --industry "e-commerce" \
  --language "en" \
  --keywords "product reviews, customer feedback" \
  --output ./datasets/sentiment-data.json
```

## Fine-tune a Model

Use the LLM Playground to fine-tune a model:

```bash
servable llm-playground fine-tune \
  --model "gpt-3.5-turbo" \
  --dataset ./datasets/sentiment-data.json \
  --output ./models/sentiment-classifier
```

## Deploy Your Model

Deploy your fine-tuned model:

```bash
servable deploy \
  --model ./models/sentiment-classifier \
  --name "my-sentiment-classifier"
```

## Test Your Deployment

Test your deployed model using the AI Gateway:

```bash
curl -X POST https://api.servable.dev/v1/models/my-sentiment-classifier/predict \
  -H "Authorization: Bearer $SERVABLE_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "input": "This product is amazing! I love it.",
    "parameters": {
      "temperature": 0.1
    }
  }'
```

## Common Issues

<AccordionGroup>
  <Accordion title="Authentication Failed">
    Make sure you're logged in with `servable auth login` and your account is active.
  </Accordion>
  <Accordion title="Dataset Generation Taking Too Long">
    Large datasets can take time. Check the status with `servable data-agent status <job-id>`.
  </Accordion>
  <Accordion title="Model Deployment Failed">
    Ensure your model files are valid and you have sufficient quota. Check logs with `servable logs <deployment-id>`.
  </Accordion>
</AccordionGroup>
